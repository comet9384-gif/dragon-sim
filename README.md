# dragon-sim

Сипилятор дракона: облик (цвет, чешуя, крылья, седло, аксессуары), охота и добыча руд по биомам, инвентарь, разные виды мяса, печь и верстак, журнал логова.

## Запуск

Открой `index.html` в браузере или включи GitHub Pages для ветки `main`. Состояние хранится в localStorage этого браузера.

## Редактор базы данных

`editor.html` — отдельная страница для правки игровой базы: предметов, рецептов крафта и таблиц добычи.

Вкладки:

- **Предметы** — список предметов с id, названием, группой и характеристиками (сытость, энергия и т.д.). Можно добавлять предметы и удалять лишние.
- **Рецепты** — рецепты крафта: входные предметы с количеством, выход, статус и разблокировка.
- **Добыча** — таблицы добычи по биомам: шансы выпадения предметов при охоте и добыче руды, а также минимальные и максимальные количества.
- **JSON** — сырой вид всей базы, кнопки копирования и скачивания.

Редактор проверяет данные перед сохранением: id должны быть непустыми и без пробелов, дубликаты id не пропускаются, в рецептах сверяются входы и выходы, в таблицах добычи — веса и диапазоны количеств. Ошибки выводятся списком над полями.

База хранится в localStorage ключа `dragon-sim-db-v1` и сохраняется автоматически при каждой правке. Кнопки в шапке:

- **Экспорт JSON** — скачать базу файлом `dragon-sim-db.json`.
- **Импорт JSON** — загрузить базу из файла (с проверкой формата).
- **Сброс** — вернуть исходные данные по умолчанию.

## Связь игры и редактора

Игра (`index.html`) умеет подгружать базу, отредактированную в `editor.html`:

- кнопка **«Загрузить из редактора»** в карточке «База данных» читает ключ `dragon-sim-db-v1` из localStorage и подставляет предметы, рецепты и добычу в игру (работает, когда обе страницы открыты в одном браузере, например на GitHub Pages);
- кнопка **«Загрузить из файла JSON»** принимает экспортированный из редактора файл.
