# dragon-sim

Симулятор дракона: облик (цвет, чешуя, крылья, седло, аксессуары), охота и добыча руд по биомам, инвентарь, разные виды мяса, печь и верстак, журнал логова.

## Запуск

Открой `index.html` в браузере или включи GitHub Pages для ветки `main`. Состояние хранится в localStorage этого браузера.

## Состояние

Седла и аксессуары открываются крафтом. Старые сохранения версии 1 не переносятся.
